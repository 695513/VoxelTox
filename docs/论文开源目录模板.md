# BVCNN 论文代码目录模板

这是整理项目时使用的结构建议，保留作参考。现有文件已按此建议归类，实际目录与可用命令以项目根目录 `README.md` 为准；下面标为“待补充”或“可选”的功能不代表已实现。论文代码没有统一强制目录标准，重点是让读者能找到数据准备、预训练、微调和评估入口，并按说明复现实验。

## 1. 建议结构

```text
BVCNN/
├── README.md                       # 项目介绍、安装、数据和权重、运行步骤、结果
├── requirements.txt                # 主流程依赖
├── .gitignore                      # 排除本地缓存、权重、日志和临时文件
├── LICENSE                         # 按作者/机构授权选择；第三方数据授权单独说明
├── CITATION.cff                    # 可选：论文引用信息
│
├── core.py                         # 现有模型、数据读取、损失函数等公共组件
├── train.py                        # 现有七个下游任务的统一训练入口
├── evaluate.py                     # 待补充：加载下游权重，独立评估测试集
│
├── pretrain/
│   └── pretrain.py                 # 预训练模型、重建/对齐目标和训练入口
│
├── preprocessing/
│   ├── pretrain_voxelize.py        # 从最终预训练 SDF 生成体素缓存
│   └── downstream_voxelize.py      # 从下游 CSV 和固定划分生成体素缓存
│
├── configs/                        # 可选：后续把代码中的参数提取为配置文件
│   ├── pretrain.yaml
│   └── downstream/
│       ├── bbbp.yaml
│       ├── bace.yaml
│       └── ...
│
├── splits/
│   └── scaffold/                   # 固定划分；建议纳入 Git 版本管理
│       ├── bbbp.pkl
│       ├── bace.pkl

│       ├── clintox.pkl
│       ├── ames.pkl
│       ├── herg.pkl
│       └── dili.pkl
│
├── data/
│   ├── README.md                   # 来源、版本、下载链接、样本数和处理规则
│   ├── raw/                        # 下游 CSV：允许再分发时可纳入仓库
│   ├── pretrain/                   # 最终预训练 SDF：单独下载到这里
│   └── cache/                      # 生成的缓存：单独下载或本地生成

│
├── results/
│   ├── README.md                   # 论文结果对应的配置、种子和检查点
│   └── summary.csv                 # 可选：公开的汇总指标
│
├── assets/                         # 可选：README 展示的架构图、示意图
├── environment/                    # 已整理的环境来源、库清单和检查记录
```

初次发布可以继续把参数保留在 `train.py` 中，不必为了目录形式先拆出 YAML。代码规模扩大后，再将 `core.py` 拆成模型、数据读取、损失函数等模块。保持当前 `train.py` 与 `core.py` 同目录，可以继续使用现有的 `import core`。

## 2. 现有文件怎么对应

| 当前内容 | 模板中的位置 | 整理要点 |
|---|---|---|
| `core.py`、`train.py` | 根目录同名文件 | 统一路径默认值或明确命令行参数 |
| `预训练/pretrain.py` | `pretrain/pretrain.py` | 将缓存和输出路径改为项目配置；已改成从第 1 轮开始 |
| `预训练/预训练体素化多进程3.py` | `preprocessing/pretrain_voxelize.py` | 明确 SDF 输入与缓存输出位置 |
| `xiayouyuchuli.py` | `preprocessing/downstream_voxelize.py` | 明确 CSV、固定划分及缓存路径 |
| `预训练/voxel_preprocessor.py` | 可选放 `legacy/` | 备用脚本，与当前主流程区分；使用时另需 `timeout-decorator` |
| `raw/` | `data/raw/` | 保留实际使用的 CSV 与来源信息 |
| `split/scaffold/` | `splits/scaffold/` | 保留与 CSV 行顺序对应的固定划分 |
| `下游任务数据集体素化缓存/` | `data/cache/` | 保留 `BVCNN-任务名/train、val、test` 的层级 |
| 最终预训练 SDF | `data/pretrain/` | 提供单独下载链接，无需将全部原始分片一起放入代码仓库 |
| 第 23 轮预训练权重 | `weights/` | 标明对应实验版本 |
| `下游任务结果权重/` | `weights/downstream/` | 标明任务、种子、配置、指标和模型选择方式 |
| 大体积运行日志 | 单独归档或下载 | 可公开结果汇总，不必把所有日志加入 Git 历史 |

移动文件后，需要同步修改路径引用。仅重命名目录不能使现有绝对路径自动生效。

## 3. README 可用模板

```markdown
# BVCNN

论文标题、作者、论文链接和项目简介。

## 安装

推荐系统与 Python 版本；创建环境；安装对应的 PyTorch；安装 requirements.txt。
详见 environment/README.md。

## 数据与权重

- 下游数据：来源、版本、标签列、下载位置。
- 固定骨架划分：splits/scaffold/；索引与对应 CSV 的行顺序一致。
- 预训练数据：最终 SDF 的下载链接、文件大小、校验和、预处理规则。
- 预训练权重：下载链接及保存位置。
- 下游权重：各任务下载链接、对应配置和种子。
- 体素缓存：生成方法或下载链接及保存位置。

## 运行

1. 准备原始数据和固定划分。
2. 生成或下载体素缓存。
3. 从头预训练，或下载已有预训练权重。
4. 使用指定预训练权重进行下游微调。
5. 加载下游权重，独立评估测试集。

每一步写出经验证的完整命令、工作目录和必要参数。

## 结果

列出任务、指标、种子、验证集模型选择规则及对应检查点。
如报告均值与标准差，应给出重复实验设置。

## 引用与授权

论文引用格式、代码许可证、第三方数据/模型来源及其授权说明。
```

模板布局完成且文件已放入对应位置后，现有下游训练入口可以使用如下参数。从项目根目录执行：

```bash
python train.py --dataset bace --seed 42 --cache-dir data/cache/BVCNN --split-dir splits/scaffold --pretrained-path weights/pretrain_model_epoch_23.pth --chemberta-path DeepChem/ChemBERTa-77M-MLM
```

`--cache-dir` 是前缀，代码会自动追加 `-bace`，因此对应目录为 `data/cache/BVCNN-bace/`。这条命令是模板布局下的示例，尚未在重组后的目录中运行。预训练脚本当前未提供同样的命令行路径参数，需要先调整其入口路径。

独立评估入口 `evaluate.py` 当前尚未提供。补充时应加载指定下游检查点，并使用与该检查点一致的模型配置、ChemBERTa 特征处理和测试缓存；不用重新训练即可计算指标。

## 4. .gitignore 可用模板

```gitignore
__pycache__/
*.py[cod]
.idea/
.vscode/
.venv/
.env

# 大数据与生成缓存；小型下游 CSV 和固定划分可另行纳入仓库
/data/cache/
/data/pretrain/

# 权重通过独立下载提供，保留说明文件
/weights/*
!/weights/README.md

# 运行输出；保留公开说明和汇总结果
/results/*
!/results/README.md
!/results/summary.csv

*.bak
*.log
*.xltd
*.xltd.cfg
*.qkdownloading
```

不要直接全局忽略 `*.pkl`：当前骨架划分就使用 `.pkl`，应随仓库提供。这个忽略模板以完成上述目录整理为前提；直接应用到当前中文目录结构时，需要增加对应的实际缓存和权重路径。
